## ✨ 这是什么样的游戏？

星际殖民地是一款**完全自运转**的浏览器多人在线策略游戏。你在宇宙中建立殖民地，开采资源，发展科技，参与股市期货投机，与其他玩家展开领地争夺、派系战争、竞技场对决，甚至派遣间谍渗透敌方。

游戏内置了 **NPC AI 聊天系统**，数十个 AI 驱动的 NPC 会围绕经济、政治、军事等话题展开实时讨论，让游戏世界始终充满生机。

**所有代码由 AI 生成，所有玩法由 AI 设计。**

## 🎯 V9.0 核心玩法

### 🏗️ 殖民建设
- 3×3 格子建造系统，5 种建筑类型
- 4 种星球类型：类地 / 荒漠 / 冰封 / 火山
- 9 种资源：矿物、能量、食物、金币、稀有金属、水晶、等离子体、纳米材料、暗物质
- 6 大专精路线：军事、经济、文化、科研、工业、贸易

### 📈 股市交易
- 8 支动态股票，AI 实时驱动价格
- **暴涨暴跌机制**：标准差 0.045，5% 概率触发黑天鹅事件（±8%）
- 涨跌停板 ±10%，T+1 结算
- 买入滑点 0.5~2%，手续费 0.3% + 印花税 0.1%
- **约 90% 的玩家在股市中亏损** —— 真实模拟金融市场

### 📊 期货市场
- 1-10 倍杠杆多空双向交易
- 4 种可交易资源期货
- 开仓/平仓各 0.5% 手续费

### 🗺️ 星际领地
- 多块可占领领地，每 30 分钟自动产出资源
- 攻击/防御力系统，实力决定占领成败
- **一键收取全部领地** / **一键夺取**

### ⚔️ 战争系统（V8 核心）
- **袭击系统**：6 种攻击阵型（均衡/突击/围城）和 6 种防御阵型（堡垒/伏击/撤退）
- **防御工事**：4 级防御建筑可建造升级
- **战报中心**：完整的战斗日志，多阶段战斗过程
- **战争疲劳**：7 天内超过 3 次袭击后收益递减
- **新手保护**：7 天内且等级 < 4 受保护
- **护盾系统**：购买护盾免疫袭击

### 🛡️ 派系战争
- 4 大派系：星河联邦 / 暗影军团 / 知识圣殿 / 自由联盟
- 宣战 / 和平协议 / 联盟体系
- 战争贡献度排名，影响跨模块联动（股票市场军工板块）

### 🏟️ 竞技场
- ELO 评分系统，6 大段位（新兵 → 传奇）
- 每小时自动匹配对战
- 下注围观系统

### 🗡️ 赏金系统
- 玩家可对仇敌悬赏，悬赏越高吸引力越大
- 复仇系统：被袭击 +1 复仇令，复仇袭击 1.5x 掠夺加成
- 12 小时赏金过期自动退还

### 🕵️ 间谍行动
- 4 种间谍行动：窃取资源 / 破坏建筑 / 盗取情报 / 策反
- 成功率和防御等级对抗

### 🚀 星际探索
- 派遣舰队探索未知星域
- 8 大星区等你去发现

### ⚗️ 资源合成
- 基础资源合成高级资源（稀有金属/水晶/等离子体/纳米材料）
- **一键快速合成**：自动计算最大可合成数量

### 💬 AI 聊天室
- 数十个 NPC 智能体，各具人格特质（学术型 / 话痨型 / 粗暴型 / 神秘型等）
- 围绕经济、政治、军事话题**群体讨论**而非各说各话
- 50% 概率发起话题讨论，30% 概率回应他人

### 🏆 成就 & 每日任务
- 20+ 种成就，覆盖建设/交易/战斗/探索
- 每日任务系统，完成获得额外奖励

### 📋 更多
- 排行榜系统
- 论坛发帖
- 上帝模式（特殊指令）
- 管理后台（NPC 管理、市场干预、数据修改等）
- 通知中心

## 🏗️ 技术架构

```
┌─────────────────────────────────────────────┐
│                    Nginx                     │
│               (反向代理 + 静态文件)            │
├──────────┬──────────┬───────────┬────────────┤
│ Frontend │ Backend  │  Admin    │  Database  │
│ (HTML)   │ (FastAPI)│ (FastAPI) │  (MySQL)   │
│ :80      │ :8000    │ :58018    │  :3306     │
├──────────┴──────────┴───────────┴────────────┤
│              Redis (缓存 + 会话)               │
│                  :6379                        │
└──────────────────────────────────────────────┘
```

| 组件 | 技术 | 说明 |
|------|------|------|
| 后端 | FastAPI + aiomysql + Redis | 异步高性能，~3500 行 |
| 前端 | 原生 HTML/CSS/JS | 单页应用，零框架依赖 |
| 数据库 | MySQL 5.7 | 40+ 张表 |
| 反向代理 | Nginx | 静态文件 + API 代理 |
| 容器化 | Docker Compose | 5 容器一键部署 |
| AI 引擎 | 定时任务 + 随机算法 | 股市驱动、NPC 对话、事件系统 |
| 后台管理 | FastAPI + 独立端口 | NPC 管理、市场干预、数据看板 |

## 🚀 一键部署

```bash
# 1. 克隆仓库
git clone https://github.com/wangcc7/space-colony.git
cd space-colony

# 2. 启动（需先安装 Docker & Docker Compose）
docker-compose up -d --build

# 3. 查看状态
docker-compose ps

# 4. 查看后端日志
docker-compose logs -f backend
```

访问 `http://<你的IP>/` 即可开始游戏。管理后台位于 `http://<你的IP>:58018/admin`。

### 环境要求

- Docker 20.10+
- Docker Compose v1 或 v2
- 2GB+ 可用内存
